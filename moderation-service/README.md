# Локальная модерация Стровы

Восстановлена из сентябрьского пакета и обновлений 6, 7, 12 и 13 октября 2026 года, дополнена 14 ноября. Установка: `RESTORE-MODERATION-RU.md` в корне пакета.

`POST /moderate` требует Bearer-токен. Порт открыт только на `127.0.0.1:8091`; его нельзя публиковать через nginx. `/health` готов после загрузки всех моделей, включая речь. Общий секрет сайта и модератора создаёт установщик.

Используются Sentence Transformers, CLIP с отдельным многоязычным текстовым кодировщиком, OpenNSFW2, Tesseract rus+eng и Whisper tiny. Работа на CPU, платный API не нужен. Используются ресурсы оплаченного VPS.

Проверяются все фото, до 48 кадров каждого видео и звуковая дорожка до 180 секунд. Более длинное видео, анимированное многокадровое изображение и ошибки распознавания требуют ручной проверки. HEIC/HEIF поддерживается через pillow-heif. Словарь app/moderation-language.json идентичен src/data/moderation-language.json сайта; OCR и речь проверяются по нему тоже.

Нарушение даёт rejected, сомнение — manual_review. Ошибка скачивания, модели, OCR или декодирования не разрешает публикацию. Прежние повторы временных ошибок, причины отказа и уведомления сохранены.

Docker: 4 CPU, 8 ГБ RAM, 512 процессов, временный диск 2 ГБ; пользователь без root, без capabilities, файловая система только для чтения, постоянный volume моделей. Автозапуск после перезагрузки VPS, ограниченные журналы. Тексты публикаций и секреты не записываются в журналы.

Скачивание: только HTTPS с точных доверенных хостов, без перенаправлений, с ограничением размера и времени. FFmpeg принимает только ожидаемые форматы контейнеров, сетевые протоколы отключены.

Проверки:

```bash
python -m unittest discover -s tests
python selftest.py
```

Self-test выполняет реальный инференс моделей, OCR тестовой надписи, извлечение кадров и запуск распознавания речи. Ничего не публикует в Firebase. Запускается установщиком ДО старта рабочего контейнера: второй набор моделей параллельно на этом VPS запускать не нужно.

Автопроверка не гарантирует стопроцентную точность. Возможны ошибки распознавания, краткие вставки между выбранными кадрами и неоднозначные объекты. Точную марку JCB по одному изображению гарантировать нельзя. Спорные случаи проверяет человек. Пороги нельзя ослаблять без проверки на размеченной выборке реальных объявлений.

```bash
docker logs --tail=60 stroika-local-moderation
curl http://127.0.0.1:8091/health
systemctl status strova --no-pager
```
